# Description
Mathematics for Economists 
Exclusively for SB&M students.  This course provides students with mathematical tools frequently used in economic analysis. Topics include real numbers, single and multivariable functions, matrix algebra, multivariate calculus, convex analysis, and constrained and unconstrained optimization. Examples of economic analysis using these mathematical tools will be included.
