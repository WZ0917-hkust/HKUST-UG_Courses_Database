# Description
Behavioral Science for FinTech 
This course integrates behavioral science theories with practical skills in design, user research, and analytics to create innovative FinTech solutions. Each week focuses on identifying barriers to desirable financial behaviors, designing interventions using behavioral science theories, and building actionable prototypes. Teams will design and refine a FinTech app feature or platform addressing real-world financial challenges.
