# Description
Strategic Investment
This course aims to help executives develop a holistic framework of strategic management in financial and real investment. It includes the investment decision-making process, key issues involved, common mistakes, tools, and the latest thinking in strategic investment. The course also helps executives to understand the macroeconomic outlook and financial markets globally.
