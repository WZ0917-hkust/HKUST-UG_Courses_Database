# Description
Language, Communication and Culture 
This course explores human language in relation to the communicative functions which it serves and the cultural context in which it is used. Issues such as how human language is distinct from other communication systems, how language is used to convey different meanings and how culture affects the use of language will be examined in order to highlight the uniqueness of human language.
