# Description
Digital Forensicsa Technical Perspective 
This course is designed to provide students with the fundamental skills and knowledge necessary for analyzing digital evidence related to cybercrime and security incidents. The curriculum will introduce investigative methods, explore techniques for processing various types of digital forensic cases, and cover essential topics such as evidence collection, forensic analysis, Windows artifact analysis, registry examination, file system analysis, and crime scene documentation methods.
