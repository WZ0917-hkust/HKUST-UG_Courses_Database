# Description
Principles of Cybersecurity 
This course introduces principles in cybersecurity. It covers the fundamental concepts and techniques of major aspects of cybersecurity, including software security, network security, cryptography, and system security. It also covers state-of-the-art techniques and solutions in advanced security topics such as data privacy protection, blockchain security, AI security, and cloud network security. Students will learn to find and fix weaknesses in different systems, and apply advanced defenses to protect these systems.
