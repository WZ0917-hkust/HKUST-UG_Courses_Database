# Description
Introduction to Mobile Robotics 
The course is to introduce the basic concepts of autonomous navigation used in mobile robotics. Course content includes navigation paradigm, common sensors, Bayes theory, Kalman filter, robot mapping, SLAM, motion planning, and software platforms for robotics research.
