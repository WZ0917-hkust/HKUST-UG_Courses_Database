# Description
Geographical Information Systems and Census Analysis 
This course provides students with comprehensive knowledge of Geographical Information Systems, including basic concepts, software and functions, data structures, and applications to social science and other fields. Students will learn fundamental geospatial concepts, census data and structures, and the joint analysis of large spatial datasets with census socio-demographics through lectures, lab exercises, and a final project.
