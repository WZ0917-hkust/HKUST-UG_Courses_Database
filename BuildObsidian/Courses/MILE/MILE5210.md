# Description
Functional Grammar in the Language Classroom 
This course takes a functional perspective to emphasize the way spoken and written language operate in different social situations. Using the systemic functional approach to language analysis, the course explores how grammar and discourse features can be used to teach language in context. It focuses on the knowledge and skills needed to design and implement effective language teaching materials that incorporate Functional Grammar principles in the language classroom and examines the benefits and drawbacks of using a functional approach to language pedagogy. For MA(ILE) students or students with program director or course instructor's approval only.
