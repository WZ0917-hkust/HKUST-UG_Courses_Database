# Description
Programming R for Analytics 
This course introduces students to R Programming language and its important tools for programming, data visualization, and business analytics. Students will learn common data structures, variables, and data types used in R and write R scripts and build R markdown documents to share their code to others. Furthermore, this course will provide skills for emerging business applications such as text analytics. Students will be able to effectively interface with practitioners and researchers by utilizing various packages available in R.
