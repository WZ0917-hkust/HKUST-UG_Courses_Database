# Description
Reinforcement Learning with Financial Applications 
With the application of artificial intelligence (AI) growing rapidly in finance industries and related sectors, this course introduces the use of reinforcement learning techniques in financial applications. Topics include finite action space and finite state space problem, classical RL algorithms, Q learning, policy gradient methods, and deep Q learning.
