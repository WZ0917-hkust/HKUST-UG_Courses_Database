# Description
Value Investing in Global Markets 
This course covers the basic theory and philosophy of value investing as it has developed since Graham. The styles of important value investors including Graham and Buffett will be introduced and discussed. The basic techniques of investing will also be presented: search, valuation and the construction of a portfolio. The framework developed will be adopted in class to study specific companies. This course will only focus on equities. For GBUS students only.
