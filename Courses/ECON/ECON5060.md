# Description
Applied Machine Learning for Economic and Financial Analysis 
This course introduces the applications of machine learning for economic and financial analysis. It relates different business problems to the relevant supervised and unsupervised learning tasks. Topics include valuation of property prices, macroeconomic forecasting, credit risk prediction, financial transaction fraud detection, portfolio analysis, volatility prediction, and stock market anomaly detection. Students will learn and apply basic machine learning tools to solve practical economic and financial cases.
